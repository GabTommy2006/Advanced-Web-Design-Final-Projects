# js/

Thư mục dành cho JavaScript (giai đoạn sau). Dự kiến:

- `data.js` – dữ liệu 6 nền ẩm thực × 6 món (đã có sẵn trong `dishes.html`).
- `main.js` – lời chào theo giờ ở Trang chủ, đánh dấu bữa hiện tại (`.meal.is-now`).
- `result.js` – đọc `?mode=any`, `?cuisine=viet`, `?dish=pho-bo`; chọn món ngẫu nhiên,
  đổi `data-cuisine` trên `<body>`, điền vòng quay xèng và thẻ món ăn,
  tạo link Google Maps “Tìm quán gần đây”.
